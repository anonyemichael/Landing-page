# Landing-page

A responsive institutional landing page (e.g., for a school, NGO, or local agency) that showcases the institution's mission, services, and contact information. Visitors can fill out an inquiry form — each submission generates a ticket number and stores the inquiry locally (using localStorage or a mock API).

## 📂 Project Structure

`text
├── css/
│ └── style.css # Stylesheets for layout and responsiveness
├── images/ # Project assets and background images

│ └── script.js # Logic for slider, inquiry ticket system, and UI interactions
├── index.html # Main entry point
└── README.md # Project documentation
`

## 🎨 Key Components

### Hero Section with Image Slider
The landing page features a dynamic hero section with a rotating background image slider. Each image is displayed for 5 seconds with a smooth fade and zoom transition effect.

### Services Showcase
Three core services are presented with interactive 3D flip cards that transform on hover, providing an engaging way to highlight GI-KACE's offerings.

### Gallery
A responsive grid gallery showcasing various aspects of the institution with a digital folding effect on hover.

### Inquiry Form
A fully functional contact form with client-side validation that generates a unique ticket number (e.g., GIKACE-12345) for each submission. All inquiries are stored in the browser's localStorage.

### Responsive Navigation
A mobile-friendly navigation bar with a hamburger menu that collapses on smaller screens.

## ⚙️ How to Use

1. Clone the repository:
`bash
git clone https://github.com/anonyemichael/Landing-page.git

2. Open the project:
